How verification works

Each event stores the SHA-256 hash of the previous event, so changing any past event breaks every hash after it.

Your browser recomputed all 0 hashes and prev_hash links from the raw events shown here.

The gateway signs a checkpoint with Ed25519 against /.well-known/jwks.json. Verify offline with python -m aimo.audit verify-checkpoint <checkpoint_jws>.
